# Seller Studio

Each of the ten departments retains its own seller workspace and design. Create an account, create a store profile, and publish active listings. Seller profiles, product photographs, details, stock and orders persist in MongoDB. Draft and paused products stay private. Only the owning seller can edit or delete a listing.

Published items appear in the normal buyer product catalogue. Food and fruit stores must set their pickup location, and buyers select a location within 5 km. Confirmed cash-on-delivery orders appear in the seller workspace and can advance through preparation to pickup.

See [backend setup](../../../backend/README.md) for authentication, Postman, location and delivery configuration.
